# 截图 OCR

一个仅在 Windows 本地运行的截图、贴图、标注与文字识别工具。拖动框选屏幕区域后，可以 OCR、编辑、保存、复制或将图片置顶贴在桌面。

## 直接使用

双击 `dist\ScreenshotOCR.exe`。程序运行后：

1. 点击“截图识别”，或按默认全局快捷键 `Ctrl + Alt + O`。
2. 按住鼠标左键拖动框选文字区域。
3. 松开鼠标后执行所选操作；右键或 `Esc` 可取消截图。

识别结果可复制、编辑或保存为 UTF-8 文本。整个 OCR 过程调用 Windows 本地接口，截图不会上传。

主按钮右侧的下拉菜单提供“截图并编辑、截图后贴图、截图并保存、截图并复制图片”。截图完成后，预览区也可以随时编辑、贴图、保存或复制最后一张截图。

## 功能

- 支持多显示器与不同 DPI 缩放
- 自动读取 Windows 已安装的 OCR 语言
- 中文界面、简体中文识别
- 小字放大与轻度对比度增强
- 识别后自动复制
- `Ctrl + Alt + O` 全局快捷键
- 关闭窗口时询问“后台运行 / 彻底退出 / 取消”
- 系统托盘菜单，可在后台继续截图
- 图片保存为 PNG/JPG、复制到剪贴板
- 无边框置顶贴图，支持拖动、滚轮缩放和右键菜单
- 图片编辑器：画笔、矩形、椭圆、箭头、文字、马赛克、裁剪、旋转、撤销/重做
- 设置页：关闭行为、快捷键、默认截图动作、保存文件夹与格式
- 可选开机自启，启动后直接进入后台托盘
- 单实例保护，避免开机自启后重复运行
- 单文件 EXE，无需单独安装 Python 或 Tesseract

## 后台运行与设置

首次关闭主窗口时会询问是否在后台运行：

- 选择“是”：主窗口隐藏到系统托盘，快捷键仍然生效。
- 选择“否”：彻底退出程序。
- 选择“取消”：返回主窗口。

可以在“设置”中将关闭行为改为始终后台运行或始终退出，也可以修改快捷键、默认截图操作以及开机自启。开机启动时程序直接进入后台托盘，不弹出主窗口。设置保存在 `%APPDATA%\ScreenshotOCR\settings.json`。

设置内容区域支持滚动，底部的“恢复默认 / 保存设置 / 取消”按钮始终固定可见，适配高 DPI 和较小屏幕。

贴图窗口默认始终置顶：左键拖动位置，滚轮缩放，右键可以复制、保存、编辑或关闭。

## 重新构建

在 PowerShell 中运行：

```powershell
.\build.ps1
```

构建脚本会创建项目内的 `.venv`、安装 `requirements.txt` 中的依赖、生成图标，并将单文件程序输出到 `dist\ScreenshotOCR.exe`。

## 系统要求

- Windows 10/11 x64
- 系统中至少安装一个 OCR 语言包

如果需要其他识别语言，请在 Windows 的“设置 → 时间和语言 → 语言和区域”中安装相应语言及其“基本键入/OCR”组件，然后重新启动本程序。
